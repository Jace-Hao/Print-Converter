# 水洗唛打印助手（Print Converter）

洗衣管家打印出来的水洗唛是 120×30mm 横版内容，而门店标签机（佳博 GP-9134T）按 30×120mm 竖版出纸。
本工具自建虚拟打印机捕获打印任务，自动完成：**截取对齐 → 旋转 90° → 送印 → 归档**，不再需要手动转 PDF。

> 版本 v2.0（2026-09-22）· 更新记录见 [CHANGELOG.md](CHANGELOG.md)

## 运行环境

- Windows 10 / 11 + Python 3.10+（本机为 3.14）；依赖安装：`pip install -r requirements.txt`
- 虚拟打印机「水洗唛打印助手」：由安装脚本一键创建（系统内置 PDF 驱动，无需额外软件）
- 输出：佳博 GP-9134T，「水洗唛」打印机（30×120mm @ 300dpi）

## 日常使用

1. 确认虚拟打印机就绪：控制面板 →「虚拟打印机」查看状态（本机已安装）；
2. 双击 **`启动监视.cmd`**（保持窗口开着；关掉窗口 = 停止监视），或双击 `打开控制面板.cmd` 用面板控制；
3. 照旧打印水洗唛：打印时选择 **「水洗唛打印助手」**；
4. 其余全自动：自动截取、旋转、打印到「水洗唛」、归档留底。

## 布局设计器（v2.0 新增）

双击 **`打开布局设计器.cmd`**：自由设计水洗唛版面——文本（支持 `{字段}` 占位）、条码、线条，可拖动排版、模板管理、双预览（横版设计 / 竖版打印效果），可一键打印测试；勾选「用于自动打印」后，自动打印将按你的布局重排（识别失败时自动回退为原样旋转）。

## 虚拟打印机（自建）

- 创建/修复：双击 **`安装虚拟打印机.cmd`**（需管理员确认一次）
- 卸载：双击 **`卸载虚拟打印机.cmd`**
- 状态：控制面板 →「虚拟打印机」

## 首次使用建议

- 先打印一张真实水洗唛试跑，核对方向与位置；如需对比，双击 `打印校准唛.cmd` 会打出两版（顺时针/逆时针）各一张，选与日常一致的那版（详见说明书第 4 节）。
- 需要开机自动运行：右键 **`安装开机自启.ps1`** → 使用 PowerShell 运行（如提示权限不足，用管理员身份运行）。

## 目录说明

|---|---|
| `app\` | 程序代码（watcher 监视引擎、capture 捕获器、layout 布局引擎、designer 布局设计器等） |

| `config.json` | 运行配置（旋转方向、捕获、布局等） |
| `inbox\` | 手动投递目录：把 PDF 放进来会被自动处理 |
| `启动监视.cmd` / `停止监视.cmd` | 启停后台监视 |

| `安装虚拟打印机.cmd` / `卸载虚拟打印机.cmd` | 虚拟打印机的安装与卸载 |
| `安装开机自启.ps1` / `卸载开机自启.ps1` | 开机自启的安装与卸载 |
| `docs_build\` | 《使用说明与交付报告.docx》生成脚本（备用） |
| `开发工具\` | 可选开发脚本：版面实验室与链路自测 |
| `文档素材\` | 示例图片（见上方「效果示例」） |

详细使用说明见 **《使用说明与交付报告.docx》** 或 **《使用说明.html》**。

## 命令行（进阶）

```
python -m app.cli watch            # 常驻监视
python -m app.cli once 文件.pdf    # 处理单个文件（--dry-run 只预览不打印）
python -m app.cli calibrate        # 打印两版校准唛
python -m app.cli printers         # 打印机与分辨率信息
python -m app.cli vp status        # 虚拟打印机状态（install/uninstall 安装卸载）
python -m app.cli recognize 文件.pdf           # 识别标签字段（JSON 输出）
python -m app.cli design                       # 打开布局设计器
python -m app.cli layout --json '{...}' --print # 按布局模板打印
python -m app.cli label --json '{...}' --print # 渲染/打印固定版式标签
```

## 技术要点

- 捕获来源：自建虚拟打印机「水洗唛打印助手」写入的捕获文件（静默、无需手动保存）；旧 pdfFactory 通道仍作兜底监听；
- 输出：佳博 GP-9134T，「水洗唛」打印机，30×120mm @ 300dpi 单色位图（GDI 直打）；
- 安全闸：内容不在标签区域内的文件不会被打印，会移入 `out\hold\` 待人工确认；
- 布局：可选「按自定义布局重排」模式（`pipeline.render_mode=layout`），识别失败自动回退；
- 合规：不修改洗衣管家本体及其数据；相关配置改动前均已备份。
