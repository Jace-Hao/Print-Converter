# 水洗唛打印助手（Print Converter）

洗衣管家打印出来的水洗唛是 120×30mm 横版内容，而门店标签机（佳博 GP-9134T）按 30×120mm 竖版出纸。
本工具自建虚拟打印机捕获打印任务，自动完成：**截取对齐 → 旋转 90° → 送印 → 归档**，不再需要手动转 PDF。

> 版本 v2.1（2026-09-22）· 更新记录见 [CHANGELOG.md](CHANGELOG.md)

## 一键安装（推荐）

从 [Releases](https://github.com/Jace-Hao/Print-Converter/releases) 下载安装包（资源名 **`Print-Converter-Setup-v2.1.exe`**）：

1. 双击安装包 → 选择安装目录 → 完成（约 1 分钟）；
2. 安装程序自动完成：虚拟打印机「水洗唛打印助手」、开机自启、配置初始化、快捷方式；
3. 安装后双击桌面/开始菜单的「打开操作页面」即可使用。

> 安装包已内嵌独立运行环境，**无需预装 Python 或其它软件**；卸载通过「控制面板 → 应用」或开始菜单卸载项完成。

## 运行环境（免安装 / 开发部署）

> 使用一键安装包时无需本节内容（运行时已内嵌）。

- Windows 10 / 11 + Python 3.10+（本机为 3.14）；依赖安装：`pip install -r requirements.txt`
- 虚拟打印机「水洗唛打印助手」：由安装脚本一键创建（系统内置 PDF 驱动，无需额外软件）
- 输出：佳博 GP-9134T，「水洗唛」打印机（30×120mm @ 300dpi）

## 日常使用

1. 双击 **`打开操作页面.cmd`**：软件在后台静默启动（无窗口），浏览器自动打开「操作页面」；
2. 照旧打印水洗唛：打印时选择 **「水洗唛打印助手」**；
3. 其余全自动：截取 → 旋转 → 打印到「水洗唛」→ 归档。

> 软件已设置**开机自启**：开机登录后自动在后台运行，平时无需手动启动；需要退出时双击 `停止软件.cmd`。

## 操作页面

浏览器访问 `http://127.0.0.1:8787/`（仅本机可访问），统一完成：状态查看、虚拟打印机检测/修复、打印校准唛、打开各目录、查看最近处理与运行日志。页面文案与配色在 `web\操作页面.html` 中（文件顶部有修改指引）。

## 虚拟打印机（自建）

- 创建/修复：双击 **`安装虚拟打印机.cmd`**（需管理员确认一次）
- 卸载：双击 **`卸载虚拟打印机.cmd`**
- 状态：操作页面 →「虚拟打印机」

## 首次使用建议

- 先打印一张真实水洗唛试跑，核对方向与位置；如需对比，双击 `打印校准唛.cmd` 会打出两版（顺时针/逆时针）各一张，选与日常一致的那版（详见说明书第 4 节）。
- 开机自启已装好；如需撤销：右键 `卸载开机自启.ps1` → 使用 PowerShell 运行。

## 目录说明

| 目录 / 文件 | 说明 |
|---|---|
| `app\` | 程序代码（watcher 监视引擎、capture 捕获器、console 后台服务、cli 命令行等） |
| `web\` | 操作页面（本地页面文件） |
| `out\archive\` | 每次打印自动归档的 PDF 原件（补打用；运行时自动创建） |

| `out\logs\` | 运行日志（排查问题先看这里） |
| `spool\` | 虚拟打印机捕获文件与作业暂存（运行数据） |
| `config.json` | 运行配置（旋转方向、捕获、打印参数等） |
| `inbox\` | 手动投递目录：把 PDF 放进来会被自动处理 |
| `打开操作页面.cmd` / `停止软件.cmd` | 启动软件（后台）并打开操作页面 / 停止软件 |
| `打印校准唛.cmd` / `把PDF拖到这里处理.cmd` | 校准 / 手动处理单个 PDF |
| `安装虚拟打印机.cmd` / `卸载虚拟打印机.cmd` | 虚拟打印机的安装与卸载 |
| `安装开机自启.ps1` / `卸载开机自启.ps1` | 开机自启的安装与卸载 |
| `卸载清理.ps1` | 卸载清理：停止本目录服务 / 移除本目录的自启与虚拟打印机（安全限定，不影响其它安装） |
| `构建工具\安装包\` | 安装包构建：Inno Setup 工程 + 一键构建脚本（可复现） |
| `extras\` | 未启用的可选组件存档（布局设计器等，原样保留） |
| `docs_build\` | 《使用说明与交付报告.docx》生成脚本（备用） |
| `开发工具\` | 可选开发脚本：版面实验室 |
| `文档素材\` | 示例图片 |

详细使用说明见 **《使用说明与交付报告.docx》** 或 **《使用说明.html》**；维护与交接请见 **《开发交接文档》（开发交接文档.md / 开发交接文档.html）**。

## 命令行（进阶）

```
python -m app.cli console          # 启动后台服务 + 操作页面（等同软件主进程）
python -m app.cli once 文件.pdf    # 处理单个文件（--dry-run 只预览不打印）
python -m app.cli calibrate        # 打印两版校准唛
python -m app.cli printers         # 打印机与分辨率信息
python -m app.cli vp status        # 虚拟打印机状态（install/uninstall 安装卸载）
python -m app.cli cleanup          # 立即清理归档/预览过期文件
python -m app.cli init             # 安装后初始化（规范化配置路径）
python -m app.cli info 文件.pdf    # PDF 页面几何信息
```

## 技术要点

- 捕获来源：自建虚拟打印机「水洗唛打印助手」写入的捕获文件（静默、无需手动保存）；旧 pdfFactory 通道仍作兜底监听；
- 输出：佳博 GP-9134T，「水洗唛」打印机，30×120mm @ 300dpi 单色位图（GDI 直打）；
- 安全闸：内容不在标签区域内的文件不会被打印，会移入 `out\hold\` 待人工确认；
- 后台服务：单实例保护 + 开机自启；操作页面仅监听 127.0.0.1（不对外网开放）；
- 合规：不修改洗衣管家本体及其数据；相关配置改动前均已备份。
