# 验证脚本（历史归档）

本目录收录开发期间使用的验证 / 回归脚本，供后续维护时复用。

**注意**：脚本内含开发机绝对路径（`E:\软件开发\...`），换环境运行前请先调整；其中个别脚本会**真实打印**测试内容（见下表）。涉及文件槽的脚本建议先停止后台服务再运行，避免与运行中的实例抢同一捕获槽。

| 脚本 | 用途 | 会打印吗 |
|---|---|---|
| `stage2_tests.py` | 版面截取 / 对齐验证（截取区域 + 2.03mm 对齐补偿的逐像素检查） | 否（dry_run） |
| `stage3_live.py` | 实况捕获测试：向虚拟打印机瞬间连打，验证捕获链路（含一次实体出纸烟测） | 是（少量测试唛） |
| `capture_test.py` | 文件槽捕获冒烟测试（写入样例 → 验证捕获与处理） | 视参数 |
| `test_cleanup.py` | 每日清理功能测试（造过期 / 新鲜文件，验证保留策略） | 否 |
| `preflight_slot.py` | 启动前槽位预检（避免重启后重复处理上次捕获） | 否 |
| `mk_dup_b.py` | 生成「复打测试」PDF（配合 do_dup_b 使用） | 否 |
| `do_dup_b.py` | 复打回归：同一文件双写，验证「内容 + 写入时间」判重逻辑（鞋类双张问题修复的回归用例） | 是（会处理一次测试内容） |

> 参考：以上脚本曾在 2026-09-22 的版面对齐、连打捕获、双张修复、每日清理等验证环节实际使用，结果记录见仓库提交历史与本项目《开发交接文档》。
