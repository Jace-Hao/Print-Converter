# 未启用的可选组件（存档）

本目录存放 v2.0 版随附、当前版本（v2.1 精简版）中**未启用**的组件，原样保留：

| 组件 | 原入口 | 说明 |
|---|---|---|
| 布局设计器 | 打开布局设计器.cmd | 自由设计水洗唛版面（app/designer.py + app/layout.py + templates/） |
| 标签内容编辑器 | 打开标签编辑器.cmd | 识别字段并编辑打印（app/editor.py + app/labelgen.py + app/recognize.py） |
| 控制面板（旧） | 打开控制面板.cmd | tkinter 面板（app/ui.py，现由「操作页面」替代） |
| 旧启停脚本 | 启动监视.cmd / 停止监视.cmd | 命令行监视（现由后台服务 + 操作页面替代） |

**说明**：
- 组件源码均保持 v2.0 原样、未做修改；当前版本的主链路（虚拟打印机捕获 → 转换 → 送印 → 归档）不依赖本目录任何文件。
- 如需恢复某个组件：需要将文件移回 `app\` 目录并做少量配套改动（CLI 入口、部分配置项在 v2.1 中已移除，可参考 Git 仓库的 v2.0 提交 676646f 完整版本）。建议交由维护者处理。
