01

下载与安装

  1. 下载安装包——从 GitHub 发布页下载 水洗唛打印助手-安装包-v2.1.exe（或从交付目录获取）。
  2. 双击运行——Windows 会请求一次管理员权限（安装虚拟打印机需要），点击「是」。
  3. 选择安装目录——默认 C:\水洗唛打印助手，可改为任意目录（如 D:\水洗唛打印助手）。
  4. 保持默认勾选（推荐）——安装虚拟打印机 / 设置开机自启 / 完成后启动软件。
  5. 点击「安装」——全程约 1 分钟，完成后即可使用。
02

安装程序会自动完成

程序与运行环境复制程序文件 + 内嵌的独立运行环境（无需预装 Python）
配置初始化按当前电脑（用户名 / 目录）自动调整 config.json
虚拟打印机安装「水洗唛打印助手」并指向安装目录的捕获文件
开机自启登录 Windows 后自动在后台运行（无窗口）
快捷方式开始菜单 + 桌面「打开操作页面」
单实例保护重复启动自动忽略，不会重复处理
03

安装之后

  • 打开操作页面——双击桌面「打开操作页面」；浏览器访问 http://127.0.0.1:8787/（仅本机可访问）。
  • 日常使用——照旧在洗衣管家打印水洗唛，打印时选择「水洗唛打印助手」，其余全自动（截取 → 旋转 → 打印到「水洗唛」→ 归档）。
  • 首次建议——打印一张真实水洗唛核对方向；如需对比可运行 打印校准唛.cmd（顺时针 / 逆时针各一张）。
04

升级与卸载

  • 升级——直接双击新版安装包，选择原安装目录覆盖安装；配置与历史记录（out\ 目录）会保留。
  • 卸载——「Windows 设置 → 应用」或开始菜单 →「卸载水洗唛打印助手」。卸载会自动：停止后台服务 → 移除开机自启 → 移除虚拟打印机 → 删除程序文件；out\ 中的归档记录会保留（如需彻底清理可手动删除）。
05

常见问题

  • 安装时出现「用户账户控制」提示？——需要点击「是」（安装虚拟打印机必需）。
  • 安全软件提示/拦截？——选择放行（安装包为本地构建、未做商业签名，属常见提示）。
  • 装好后看不到虚拟打印机？——打开操作页面 →「虚拟打印机」检测/修复；或重新运行一次安装包。
  • 卸载后有残留目录？——仅剩 out\（记录）与空的 spool\，属数据保留；可手动删除。
  • 支持哪些系统？——Windows 10 / 11（64 位）；无需其它依赖。
